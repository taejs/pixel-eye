# Logo and example provenance

The 16×16 mint iris, sparkle, and blush mark was drawn on a new native pixel grid for Pixel Eye. No third-party logo or reference art was traced, downloaded or copied. The public example input is that same original mark. The SVG example was made from the PNG with Pixel Eye; the preview uses integer-scale nearest-neighbor enlargement on two backgrounds.

The 24×24 purple floppy-disk sprite is an original demonstration drawn on the native grid. The screenshot is a local browser capture of that PNG, its verified SVG export, and an intentionally edited SVG. Any earlier eye artwork is a historical test fixture, not the current branding.
